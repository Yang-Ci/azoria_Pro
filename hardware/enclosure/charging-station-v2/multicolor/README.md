# V2 黑外壳 / 白字，X2D 双色几何包

日期：2026-10-11。基于 2026-10-06 后盖修订版；底座仍为 236 × 120 mm。

正面 `10 / ULTRA / C1 / C3 / C2 / A` 为加粗白字，嵌入黑壳 0.8 mm，外表面齐平。
白字与黑壳是同一个物体的两个材料部件，随壳体一起打印，不需要装配单个字。
切片软件中的耗材编号 1 是黑壳、编号 2 是白字；耗材编号不是喷嘴编号。
其他打印部件均为黑色，沿用原有 STL。电子屏上显示的文字由电子件提供。

## 使用顺序

1. 先在 Bambu Studio 导入 `lettering-test.3mf`。选择自己的 X2D、实际喷嘴和打印板；添加黑、白两个耗材，检查对象树里 Black shell / White lettering 的耗材分配。若导入时询问，保留多个部件为同一物体。
2. 黑白两色使用相同材料体系，原型可用黑 PETG + 白 PETG；按实际耗材选择配置。先用 0.16 mm 层高、0.4 mm 喷嘴检查字的笔画和表面。试片占地 85 × 2.8 mm、高 28 mm，竖放模拟底座的字面方向，建议加 5 mm brim。
3. 同时完成原版 `fit-first/` 四个配合试件的实物试装。
4. 导入 `base-black-white-X2D.3mf`。底座已在几何文件中绕 Z 旋转 90°，占地 120 × 236 mm；若软件重新自动排列，请检查 236 mm 长边沿打印板 Y 方向。保持缩放 100%。
5. 检查耗材分组和实际供料路径，支持界面若仍使用黑色 PETG，需要确认能够清理。底座上层线仓的跨空支撑按原版说明设置。检查白字底部接触黑色基体、各笔画有实际挤出路径，检查支撑、brim、擦拭塔和打印板禁区，再导出切片结果。
6. 正式件建议从 4 圈壁、5 层顶底、20–30% 填充开始，铰链区域增加壁数。温度、流量和速度使用实际耗材配置并以试片结果调整。

X2D 官方范围：主热端单喷嘴 256 × 256 × 260 mm，双喷嘴交集 235.5 × 256 × 256 mm。
原底座宽 236 mm，直接沿 X 摆放会超过双喷嘴共同范围 0.5 mm；旋转解决此问题，
不缩小配合尺寸。来源：[官方技术参数](https://bambulab.cn/zh-cn/x2d/specs)。

## 文件与验证范围

- `base-black-white-X2D.3mf`：双色底座，保留共同坐标和颜色 / 耗材编号元数据。
- `lettering-test.3mf`：同样字样的双色试片。
- `base-black.stl` + `base-white-text.stl`：备用部件，必须作为同一物体导入，不能分别落到打印板或单独自动排列。
- `coupon-black.stl` + `coupon-white.stl`：试片备用部件，同样保留共同坐标。
- `black-white-preview.png`：基于实际导出 STL 的 CAD 外观预览。
- `validation/report.json`：闭合、流形、方向、连接块数；双色无体积重叠、无缺失、无超出；3MF 网格回读、部件分配和摆放范围检查。

这些 3MF 是未切片的几何模型，不包含已验证的 X2D 打印配置或 G-code。
尚未在 Bambu Studio 中完成真实切片验证，也未进行实物打印、装配、温升或铰链强度验证。
装配和五金仍按上一级 README.md。完整包包含其他十个沿用的 STL 和原版说明。

复现：`python3 build_black_white.py --openscad /path/to/openscad`，依赖 NumPy 和 manifold3d。
对于 CGAL 的共线零面积三角形，脚本重新划分三角面并确认顶点集合、体积不变。
生成预览需要可用的 OpenGL 显示环境。
